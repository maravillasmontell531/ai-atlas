# Sources and Data Quality

AI Atlas is a directory, not an endorsement or a guarantee of quality, availability or safety.

## Evidence priority

1. Official product page for identity and offering.
2. Official documentation/API reference for capabilities, limits and integrations.
3. Official model card, repository and release notes for exact versions/artifacts.
4. Official terms, privacy policy and license for use, retention and access.
5. Independent evaluation/reporting for comparison claims, with date and methodology.
6. Social posts/community pages as discovery leads only.

## Status

seed means discovery-only; needs_review means uncertain/incomplete; verified means core claims checked against a primary source on a recorded date; stale means facts may have changed; archived means retired but retained. The validator checks structure, not truth or link health.

## Avoid category errors

A product is not its underlying model. A family is not a checkpoint. A router is not necessarily the model creator. A framework is not automatically an agent. Record relationships explicitly.

## Time-sensitive fields

Prices, quotas, exact IDs, context sizes, API limits, regions, rollout, deprecation and licenses change. Link primary sources and record dates; never mark verified without a verification date.

## Description and URL hygiene

Use neutral original summaries. Avoid invented prices, copied marketing and unsupported rankings. Check canonical URLs without tracking codes. When renamed or retired, update status and preserve historical identity.

## Review checklist

- [ ] Correct identity and resource type.
- [ ] Canonical official URL/docs.
- [ ] Original neutral description.
- [ ] Access/pricing/license not guessed.
- [ ] Modality and model version distinguished.
- [ ] Verification date and evidence saved.
- [ ] No duplicates, tracking links or copied claims.
