# AI Glossary

**Agent:** System selecting actions from observations, often using tools. **Agent loop:** Repeated decision/action/observation to a stop condition. **Alignment:** Steering behavior toward goals/constraints. **API:** Programmatic interface. **Attention:** Mechanism relating representations. **ASR:** Speech-to-text. **Autoregressive:** Sequence generation based on prior elements. **Batching:** Processing multiple requests together. **Benchmark:** Task/data/metric/protocol. **Calibration:** Confidence matching observed frequencies. **Checkpoint:** Saved model artifact at a revision. **Chunking:** Splitting content for processing/retrieval. **Context:** Instructions, history, evidence, tools and constraints. **Context window:** Token capacity, not guaranteed recall. **Data leakage:** Improper crossing of training/test or permission boundaries. **Dataset:** Examples and metadata. **Deep learning:** Neural networks with multiple learned layers. **Dense retrieval:** Search over embeddings. **Distillation:** Training a student to reproduce selected teacher behavior. **Distribution shift:** Deployment differs from development data. **Embedding:** Vector representation. **Endpoint:** API/network access point. **Eval:** Measurement under a protocol. **Fine-tuning:** Further training to adapt behavior. **Foundation model:** Broadly trained model used across tasks. **GAN:** Generator/discriminator model family. **Generative AI:** Systems synthesizing outputs. **Generalization:** Performance outside exact training examples. **Grounding:** Linking outputs to evidence. **Hallucination:** Unsupported or incorrect output presented as reliable. **HITL:** Human-in-the-loop review. **Inference:** Running a trained model. **Instruction tuning:** Training on instruction/answer pairs. **Jailbreak:** Attempt to bypass constraints. **Knowledge graph:** Entities linked by relations. **KV cache:** Stored attention states for cheaper decoding. **Latency:** Request delay. **LLM:** Large language model. **LoRA:** Low-rank parameter-efficient adaptation. **Loss:** Training objective. **Machine learning:** Fitting patterns/policies from data. **MCP:** Model Context Protocol; permissions remain implementation-dependent. **Mixture of experts:** Model routing among specialist subnetworks. **Model card:** Model documentation. **Multimodal:** Multiple data modalities. **NLP:** Natural language processing. **Observability:** Traces, metrics and logs. **OCR:** Image-to-text extraction. **Open source:** Licensed source code; not the same as weights. **Open weights:** Public parameters that may still have restrictions. **Parameter:** Learned numerical value. **PEFT:** Parameter-efficient tuning. **Prompt injection:** Untrusted content trying to manipulate instructions/tools. **Precision:** Fraction of selected positives that are relevant/correct. **Pretraining:** Broad initial training. **Quantization:** Lower numeric precision to reduce memory or increase speed with trade-offs. **RAG:** Retrieval-augmented generation. **Rate limit:** Usage cap. **Reranker:** Reorders candidates by relevance. **Retrieval:** Finding records from a corpus. **RL/RLHF:** Reinforcement learning / RL from human feedback. **Robustness:** Performance under variation/noise. **Schema-constrained output:** Output format restriction, not truth assurance. **Semantic search:** Retrieval using meaning-oriented representations. **Serving:** Running models in production. **Sparse retrieval:** Lexical/sparse search. **Speculative decoding:** Draft/proposal technique for compatible speedups. **Temperature:** Sampling parameter, not correctness. **Token:** Model-specific unit. **Tool schema:** Function argument contract. **Throughput:** Work per unit time. **Trace:** Linked execution record. **Validation set:** Data for choosing model/configuration. **Vector database:** Store/search vectors. **VLM:** Vision-language model. **Weights:** Learned parameters. **Workflow orchestration:** Coordinating steps and state. **WER:** Speech-recognition word error rate. **Zero-shot:** Task without examples in immediate context. **Few-shot:** A few examples provided in context.

## Directory rule

A chat interface is a product; a model line is a family; an exact revision is a checkpoint; a router is a provider; a framework is developer infrastructure. Do not collapse them into a single undifferentiated AI count.
